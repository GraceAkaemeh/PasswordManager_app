# Password Manager App

A simple Python GUI application to **generate, save, and view passwords**.  
Built with **Tkinter**, this project demonstrates basic Python programming, file handling, and GUI design.

---

## Features

- Generate secure passwords automatically
- Save passwords with Company and Username
- View all saved passwords directly in the app
- Simple, clean, and user-friendly interface
