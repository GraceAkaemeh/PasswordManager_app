# 🧠 Password Manager App

A simple Python GUI application to **generate, save, and view passwords**.  
Built with **Tkinter**, this project demonstrates basic Python programming, file handling, and GUI design.

---

## 🇩🇪 Beschreibung

Der Password Manager ist eine einfache Python-Desktop-Anwendung mit grafischer Oberfläche (Tkinter).  
Sie ermöglicht das sichere Generieren, Speichern und Anzeigen von Passwörtern für verschiedene Anwendungen oder Websites.

---

## 🇬🇧 Description

The Password Manager is a simple Python desktop application with a graphical user interface (Tkinter).  
It allows users to generate, save, and view passwords for different websites or applications.

---

## ✨ Features / Funktionen

### 🇩🇪 Deutsch
- Sichere Passwörter automatisch generieren
- Passwörter mit Firma/Website und Benutzername speichern
- Gespeicherte Passwörter anzeigen
- Einfache und benutzerfreundliche Oberfläche

### 🇬🇧 English
- Generate secure passwords automatically
- Save passwords with company/website and username
- View all saved passwords
- Simple and user-friendly interface
